> 写在前面：
> 最近公司的一个跨平台移动端项目要维护更新到RN 0.62版本，这不，就开始了新的踩坑之旅。
> 那，就在此记录一下最近遇到的关于Animated的错误吧。

---

#### 1. WARN Animated: "useNativeDriver" was not specified. This is a required option and must be explicitly set to "true" or "false"

#### 2. Error: Style property 'bottom' is not supported by native animated module

#### 解决方案
> 错误，就是上面两个错误了。先说结论，也就是解决方案。

```javaScript
Animated.timing(this.animated, { 
            toValue: 0, 
            duration: 0.1 * 1000, 
            easing: Easing.linear,
            useNativeDriver: false, // 添加这一行
         }).start();
```

至此，问题得已解决。

> 为什么这么解决？
> 我只能说，问题一的警告里，写的很清楚。
