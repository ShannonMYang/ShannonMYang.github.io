> 笔者最近在做一些Vue相关的开发。涉及到赋予不同值，展示不同样式效果的问题。
>
> 于是，有了一通查资料和实践。遂，作此篇总结，以备查找之需。

---

### 如下所示
```vue.js
<div class="box-style" :class="changeClass(skin)">
</div>
 
data() {
 return {
  skin:''
 }
}
onchooseSkin(attr) {
 this.skin=attr
}, 
```

### 方案①
```vue.js
addclass(i) {
 switch (i) {
  case 0:
   return 'skinA';
  case 1:
   return 'skinB';
  case 2:
   return 'skinC';
 }
}
```

### 方案②
```vue.js
addclass(i){
 var arr = ['skinA','skinB','skinC'];
 if(i==-1) {
  return 'skinA'
 } else {
  return arr[i];
 }
}
```

> 根据个人使用情况，建议使用方法②，兼顾内容更为全面。
