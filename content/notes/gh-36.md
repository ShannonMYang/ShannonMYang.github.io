> 某天，从git上拉取了最新代码后，运行 `npm install` 直接被生出一个错误:
> `(node:23794) UnhandledPromiseRejectionWarning: Error: spawnSync /Users/yangjinlong/Shannon/WorkGitLab/GZ_JRHX/node_modules/react-native/local-cli/setup_env.sh EPERM`

------

- #### 先说结果

> 我使用的是 `yarn add audit` 命令解决了问题

- #### 错误解决参考

**设备问题**
```
npm audit fix
// 或
yarn add audit fix
```

**权限问题**
让我重装了一晚上各种包的坑，最后发现跳错坑了，TMD 是文件权限的问题
