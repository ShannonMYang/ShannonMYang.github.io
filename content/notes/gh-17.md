> 今天在处理仿网易新闻项目的页面跳转时，始终无法获取到传递过来的值，查询各种中文博客，均未有能解决问题的答案。
> 
> 后，查询英文博客和github各种issue，方得以解决。
> 遂，有此记录。

------

#### App.js中代码
```javascript
// App.js
// 主页
const HomeStack = createStackNavigator();
function HomeStackScreen() {
  return (
    <HomeStack.Navigator screenOptions={{
      headerTintColor: 'tomato',  // 导航条字体颜色
      headerStyle: { backgroundColor: '#ffe4e1' },  // 导航条的背景色
      // headerBackTitle: '返回',  // 返回按钮的现实问题
    }}>
      {/* 导航显示名字，导航当前显示的页面 */}
      <HomeStack.Screen name="网易" component={HomeScreen} options={{
         //2. 设置导航标题的“名字”和“位置”（同时给多个屏幕设置标题？）
        //  headerTitle: "新闻", 
        //  headerTitleAlign:'center',
         //3. 在headerLeft中可以完全覆盖，后退按钮，也可以使用headerBackImage
      }} />
      <HomeStack.Screen name="NewsDetail" component={NewsDetail} options={{
         //2. 设置导航标题的“名字”和“位置”（同时给多个屏幕设置标题？）
         headerTitle: "详情页", 
         headerTitleAlign:'center',
         headerMode: "screen",
      }}/>
    </HomeStack.Navigator>
  );
}
```

#### 页面跳转、传值
> 按钮点击时，触发跳转页面方法
```javascript
// Home.js
// 选中时，cell的样式和渲染
        const renderItem = ({ item }) => {
            const backgroundColor = item.docid === this.state.selectedId ? "#6e3b6e" : "grazy";

            return (
                <Item
                    item={item}
                    onPress={() => this.pushToNewsDetail(item.docid)}
                    // onPress={() => this.props.navigation.navigate('NewsDetail',{id: item.docid})}
                    style={{ backgroundColor }}
                />
            );
        };
```

> ，将要传递的值，带过去
```javascript
// Home.js
// 实现详情页面的跳转
    pushToNewsDetail(docid) {
        // console.log(docid);
        this.props.navigation.navigate('NewsDetail', {
            // 父子页面跳转传递的参数
            id: docid,
        });
    }
```

#### 接收传递的值
```javascript
// NewsDetail.js
constructor(props) {
        super(props);
        // 接收父页面传递的参数
        const id = this.props.route.params.id;
        // 设定url
        let url_api = 'http://c.m.163.com/nc/article/' + id + '/full.html';
        // console.log('id: ', id);
        this.state = {
            html: '正在加载网页',
            id: id,
            url: url_api,
        }
        // console.log(this.state.url);
    }
```
