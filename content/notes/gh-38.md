> 最近在 iOS 项目中遇到了字节和16进制字符串以及NSData之间的各种转换问题，遂有此记录。
> 此为第一篇，讲解Byte的两种类型数据，及其转换。

### 一、Byte

**Byte** 是对 **字节**的封装，其类型为 `UInt8`，`UInt8` 其实是 `unsigned char` 类型。

```objective-c
Byte a = 0x11;
```

### 二、Byte *

**Byte * ** 是声明一个字节流指针，初始方法一般用 `C语言` 方法  `malloc`。

```objective-c
Byte *a = malloc(3);
a[0] = 0x11;
a[1] = 0x12;
a[2] = 0x13;
```

### 三、Byte []

**Byte []** 是声明一个字节流数组，并开辟一段内存，一般用法为:

```objective-c
Byte a[3];
a[0] = 0x11;
a[1] = 0x12;
a[2] = 0x13;
```

在 `Byte *` 分配固定的内存空间后，用法可等同于 `Byte []`。即：

```objective-c
Byte *a = malloc(3);
Byte b[3];
```

### 四、Byte [] 转 Byte *

```objective-c
Byte bt[11];
// 计算byte数组的长度
NSInteger byteArrLength = sizeof(bt);
// byte[] 转 nsdata
NSData *Bytedata = [[NSData alloc] initWithBytes:bt length:byteArrLength];
// NSData 转 Byte*
Byte *DataByte = (Byte *)[Bytedata bytes];
```

### 五、Byte * 转 Byte []

```objective-c
// Byte * 需要申请固定内存空间
Byte *bt = malloc(5);
bt[0] = 0x11;
bt[1] = 0x12;
bt[2] = 0x13;
bt[3] = 0x14;
bt[4] = 0x15;
int j = 0;
if (bt) {
    while (bt[j] != '\0') {
       j++;
    }
}
NSLog(@"%d", j);
// Byte []
Byte by[j];
int i = 0;
if (bt) {
    while (bt[i] != '\0') {
        by[i] = bt[i];
        i++;
    }
}
for (int l = 0; l < j; l++) {
    NSLog(@"by = %d", by[l]);
}
```
