##### 工欲善其事，必先利其器。

##### 对于开发者来讲，常用指令就是如此。

```Shell
// 查看当前所在位置
pwd
```

```Shell
// 查看当前文件夹中的内容
ls
```

```Shell
// 进入指定目录
cd
```

```Shell
// 创建一个文件夹
mkdir 文件夹名称
```

```Shell
// 删除一个文件夹
rmdir 文件夹名称
```

```Shell
// 返回上一级
cd ../
```

```Shell
// 清空终端当前一屏（效果类似于你大学课堂上那种上下推拉的黑板，写满一版，往上一推）
clear
```

```Shell
// 打开一个文件
open 文件名称
```

```Shell
// 创建一个文件
touch 文件名称
```

```Shell
// 查看一个文件
cat 文件名称
```
