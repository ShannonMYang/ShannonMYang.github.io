如图所示，需求是点击全部应用图标，跳转到新的页面（组件封装的）。而此时，全部应用是由组件封装而成的，全部应用那一行也是一个组件。现在问题是，点击时，无法获取到 navigation 而报错。

#原因：

原因是在一个页面组件中调用了另一个组件，而跳转动作在被调用组件中定义。则会出现当前呈现页面的 this 与跳转动作发生的 this 不一致，导致跳转动作不能被调用。

#解决办法：

在当前呈现页面传入 navigation
