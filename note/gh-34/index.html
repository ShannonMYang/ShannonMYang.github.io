记于2021年07月09日。

最近修复了工作代码中的一些bug。在修复完，往gitlab仓库提交的时候，遇到了错误。 于是我就很纳闷了，上个月中旬提交的时候还是好好的。 身为程序猿，当然是遇到问题解决问题了。于是着手查资料，开始解决。

#执行git push 命令后，报错如下：

#查了好多资料，整体都是在说，你本地的ssh目录下，没有以rsa、pub结尾的文件。

然而，实际情况是。

不仅如此，我连gitlab上的ssh keys都是配置过的。

#所以，证明问题的症结不在此。继续找。有说是本地的git没有和ssh key链接起来。

基于有两个rsa文件，于是我将它们连接起来，但是，似乎依旧没任何效果。

#看来，问题依旧不是这个。继续寻找下去。等等，好像上面提到有两个rsa文件，会不会是多账户问题。

有了方向，继续琢磨尝试。 在 ssh目录 下创建 config 文件，然后编辑，做多账户的配置。

其规则就是：从上至下读取 config 的内容，在每个 Host 下寻找对应的私钥。这里将 GitHub SSH 仓库地址中的 git.nxxxxc.cn 替换成新建的 Host 别名如：gitlab.nxxxxc，那么原地址是：git.nxxxxc.cn:sxxxlxxxv/yxxaxx.git，替换后应该是：git.nxxxxc:sxxxlxxxv/yxxaxx.git
